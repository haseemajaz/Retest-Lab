Replay data guide / v0.22.0

One bar, two possible stories.

An OHLC bar records a high and a low, not the order prices were visited inside the bar. When one bar spans several levels, the trace records a modelling convention — not an observed sequence.

Flagged, not fixed.

The new order_ambiguity column names the ambiguity. It does not recover the true intrabar order, change the model, or prove what a live fill would have been.

01 / See it

The same bar, read two ways

Long setup: entry 100.00, stop 98.80, targets 100.72 / 101.20 / 101.80 / 102.40. One active bar has low 97 and high 103.

The bar as recorded

High 103, low 97. Every level was touched — in some order.

T4 · 102.40T1 · 100.72Entry · 100.00Stop · 98.80

OHLC cannot say which level came first.

Path A — targets first

Price rises through the targets, then falls to the stop. A reader who only sees the targets would call it a win.

T4 · 102.40T1 · 100.72Entry · 100.00Stop · 98.80

Possible, but not recorded anywhere in the data.

Path B — stop first

Price falls straight to the stop before ever reaching a target. The model records this version: stop, with stop_vs_target|target_order.

T4 · 102.40T1 · 100.72Entry · 100.00Stop · 98.80

The model chooses stop-first. That is a convention, not evidence.

Both paths produce the identical OHLC bar. No calculation on OHLC alone can distinguish them. Only finer data — tick data, or a chart replayed bar-by-bar at a smaller timeframe — could.

02 / Labels

Four labels, four situations

FILL_VS_STOP

Pending setup, entry and stop both spanned

The bar touched entry and stop while armed. The model cancels the setup (stop first) and records no fill. The other order — fill first, then stop — is equally consistent with the bar.

FILL_VS_TARGET

Fill bar also spanned a target

The model records the fill and deliberately records no target on the fill bar, because the target may have been touched before the entry. Targets are only recorded from the next bar.

STOP_VS_TARGET

Active bar spanned stop and a target

The model records stop only. If the target was reached first, a real position might have taken partial profit before the stop — the trace does not know.

TARGET_ORDER

Two or more unhit targets in one bar

The model records all of them together on that bar. Their order — and whether each was genuinely reachable in sequence — is unknown from OHLC. Already-hit targets do not count again.

03 / Try it

Run the two synthetic samples.

Both use the same long breakout (entry 100.00, stop 98.80) from sample_trace.csv.

Active bar: stop and targets in one bar
python -m reference.engine sample_order_ambiguity.csv
Bar 22 reads stop with order_ambiguity = stop_vs_target|target_order.
Fill bar: targets spanned on the fill bar
python -m reference.engine sample_order_ambiguity_fill.csv
Bar 21 reads modeled_fill with order_ambiguity = fill_vs_target and no targets recorded; bar 22 then records all four targets with target_order.

The trace viewer (TRACE_VIEWER.html) counts ambiguous bars and shows the label beside the events. The audit report adds an Order ambiguity column and a count. The comparator accepts order_ambiguity as a recorded field, so you can check it against a chart observation like any other cell.

04 / Boundaries

What the label does not do.

  • It does not change any event, level or outcome. The stop-first and fill-bar conventions are unchanged from v0.21.0.
  • It is not raised for day, session or expiry cancellations: those take precedence over price, so price order did not decide the outcome on that bar.
  • It does not cover the breakout bar itself, gaps, or levels touched on a bar that never arms. A clean bar — only one relevant level spanned — is not flagged.
  • A trace with no flagged bars is not proof of a clean sequence. It only means no single bar spanned two deciding levels. Finer-timeframe or tick data is still needed to confirm order.
  • Do not count flagged bars as wins or losses, and do not use them to estimate a win rate. Treat them as “needs finer data” and exclude or separately note them in any manual comparison.
