Research field note / v0.18.0

When numbers stop being safe.

A finite input is not a guarantee of a finite calculation. The Python reference now stops on non-finite results in checked model operations instead of silently continuing.

This is a partial safeguard—not validation.

It does not prove data quality, Pine parity, execution or profitability. Finite results can still be rounded, underflowed or otherwise inaccurate.

01 / Understand

Three different outcomes.

ERROR · STOP

Non-finite arithmetic

When a checked intermediate is infinity or NaN, the reference fails with a row and operation. No new trace or report is produced.

WARNING · REVIEW

Precision concerns

Preflight can flag visible float conversion changes and large tick counts. These warnings are partial and not every inexact value triggers them.

NOT VERIFIED

Real-world behavior

Clear checks do not verify the source, trading chart, intrabar sequence, fills, costs or market performance.

02 / Investigate

What to do when a check stops.

Read the error

The message identifies the CSV row and checked operation. For example, an extreme high minus low can overflow even when both values were finite.

row 2: non-finite model arithmetic: bar range

The reference engine, preflight and audit report use the same model. Exit 2 indicates an error; no successful trace or report was created.

Inspect the source

  1. Check the original units, prices, tick and prepared indicator values.
  2. Correct only verifiable input mistakes; never invent values to clear an error.
  3. Use a new output filename and rerun. Preserve the original data and notes.

03 / Boundaries

Checked is not exact.

What is guarded

Calculated breakout and candle distances, thresholds, tick conversion, stop/risk and target arithmetic are checked when the model actually computes them. The model still uses binary floating point.

What remains

Underflow, precision loss, uncomputed branches, data provenance and differences from Pine are not fully detected. The independent calculator uses different fixed-point arithmetic.
