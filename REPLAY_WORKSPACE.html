Offline field guide / v0.18.0

Make replay evidence useful.

A practical path from prepared bars to a documented comparison. This page is a guide; it does not run the checks or connect to a chart.

Research only—not a validation result.

The Python model is not an independent Pine test. No return, fill or trading performance is established by this workflow.

01 / Prepare

Start with comparable data.

Use actual, independently recorded observations. Keep the instrument, timeframe, source, tick, session and timezone alongside your notes.

01 / BARS

Prepare the inputs

Provide consecutive confirmed bars, with prior range and ATR, from the same chart context. The model starts idle and does not compute your indicators.

02 / PRECHECK

Review assumptions

Run preflight before tracing. It reports missing data, ignored columns, timestamp concerns and optionally off-grid OHLC prices.

03 / COMPARE

Record, then compare

Capture real observations separately and compare only those cells. Unrecorded cells are not passes; a checklist cannot prove completeness.

02 / Run locally

Use the preflight.

In a terminal, change into the extracted project folder. Python 3.10 or newer is required. Start with the synthetic sample:

Inspect the sample

python -m reference.preflight sample_trace.csv --check-tick

The sample intentionally contains omissions. Warnings are expected; it is not market data.

Inspect your own bars

python -m reference.preflight your_bars.csv --config your_config.json --check-tick --strict

Replace the filenames with your own. Omit --config to use defaults. The input files are read only.

03 / Interpret

Warnings need context.

What the new checks tell you

  • Ignored columns: catch misspellings or extra columns the trace does not use; intentional extra fields can also trigger a warning.
  • Known timestamps across gaps: compares the nearest offset-aware values across blank or naive timestamps; it cannot order the missing bars or prove cadence.
  • Tick grid: optional exact decimal check of OHLC against the configured constant tick. Adjusted feeds or instruments with variable ticks may legitimately differ. It changes nothing.

Exit codes

  • 0 Input accepted; warnings can still be present without --strict.
  • 1 Warnings found with --strict.
  • 2 Invalid input or an error. No successful check was completed.

A clear preflight does not verify data provenance, sufficient warm-up, timeframe, timezone mapping or Pine parity.

04 / Audit report

Keep the evidence together.

Generate a local HTML report combining preflight warnings, the reference trace, optional observation comparison and SHA-256 input fingerprints. Hashes identify bytes, not trustworthy sources.

Try a synthetic example

python -m reference.audit_report --bars sample_trace.csv --observations sample_observations.csv --required sample_required.csv --output audit.html

Open audit.html locally after the command finishes. Choose a new output name; existing files are never replaced.

Understand the boundaries

Inputs are read sequentially and may contain private information. A match covers only supplied cells, not all behavior. The report does not run Pine or prove returns.
