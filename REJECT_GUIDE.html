Replay data guide / v0.24.0

Why no setup on this bar?

A bar with no setup is not a missing bar. The trace now names the first check that rejected the breakout candidate, so you can see whether it was price, a filter, or risk geometry.

First failure only.

reject_reason names the first failing check in a fixed order. A bar can fail more than one check — fixing the named one may reveal the next. It does not change any rule.

01 / State machine

Where a rejection happens

A rejection only matters while the model is idle. Once armed or active, the bar is judged by the setup already in force, not by a new breakout.

IDLE

Waiting for a breakout. A rejection is recorded here.

→

ARMED

Breakout passed every check. Waiting for a retest, up to expiry.

→

ACTIVE

Retest filled (modelled). Waiting for stop or targets.

→

IDLE

Stop, final target, expiry, or cancel. Cooldown, then waiting again.

Cancel reasons are separate: day_rollover, outside_session, expired, stop_before_fill. They end a pending setup; reject_reason explains why a new one never started. A reason is recorded only on a bar that started idle and did not arm — bars already armed or active carry none, so a fill or target bar never shows a rejection.

02 / Reasons

Every label, in check order

ReasonWhat it meansWhat to check
warmupNo prior high, low or ATR supplied for this bar.Supply enough preceding history; the model starts idle.
invalid_barUnconfirmed bar, or high ≤ low.Feed / prepared data; confirmed bars only.
zero_atrPrior ATR is zero or negative.ATR preparation; a zero ATR cannot size a body or risk.
no_breakoutClose broke neither the prior high nor the prior low.Most bars. This is the normal case, not an error.
direction_disabledIt broke out, but longs (or shorts) are off.Your direction settings.
min_breakBreakout distance below the minimum ATR multiple.min_break_atr; a shallow break is not a displacement.
close_directionClose is on the wrong side of open for that direction.The candle itself; a long needs close > open.
weak_bodyBody smaller than body_mult × prior ATR.Body threshold; a small body is not a displacement candle.
close_edgeClose too far from the candle edge (wick too long).edge; the close must sit in the outer 25% by default.
emaEMA filter on, and close is on the wrong side of EMA (or EMA missing).EMA value and length; missing EMA fails the filter.
vwapVWAP filter on, and close is on the wrong side of VWAP (or VWAP missing).Session VWAP; intraday sessions and anchors matter.
volumeVolume filter on, and volume is below the multiple (or volume data missing).Volume and prior average; missing data fails the filter.
risk_out_of_rangeEntry-to-stop distance outside the min/max ATR range, or below one tick.Stop buffer and risk limits; the setup is not tradeable at this size.
targets_collapsedAfter tick rounding, entry and targets are not strictly increasing.Tick size; on a coarse tick the targets can collapse into one price.

03 / Try it

Run the synthetic sample.

python -m reference.engine sample_reject.csv
Bar 20: weak_body. Bar 21: close_edge. Bar 22: no_breakout. Bar 23: arms long.
Check Pine and Python agree
python -m reference.parity --pine retest_lab.pine
Compares every shared input default. A match is settings agreement, not chart parity. Tick is the instrument mintick in Pine — set the Python tick to match it manually.
Validate an alert payload
python -m reference.alerts sample_alert.json
Checks the v3 JSON shape only. It does not prove the alert fired on a real chart.

The audit report counts rejection reasons and ambiguity labels separately, and counts ambiguous bars apart from clean event bars. Its timeline shows the rejection reason for each event bar, and its summary states the rejected-while-idle count and the most common reason. The trace viewer shows a per-reason breakdown with filters for rejected and ambiguous bars, and the comparator accepts reject_reason as a recorded field.

04 / Boundaries

What a rejection does not mean.

  • A rejected bar is not a missed trade. The model only arms on bars that pass every check; most bars correctly reject.
  • Changing a threshold to make a favourite bar arm is curve-fitting, not validation. Change a setting deliberately, record why, and re-check the whole trace.
  • Filters fail closed: a missing EMA, VWAP or volume value rejects the candidate. That is by design — a filter with no data cannot pass.
  • The reason order is fixed and documented in reference/engine.py (diagnose). It is not the only failing check, and it does not rank which failure matters most.
